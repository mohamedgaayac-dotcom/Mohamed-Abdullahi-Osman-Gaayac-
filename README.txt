# Eng-Gaayac Portfolio

Personal portfolio for Mohamed Abdullahi Osman (Eng-Gaayac).

## Files
- `index.html` — portfolio page
- `style.css` — responsive styling
- `supscribt.js` — dark/light mode, mobile menu and button interactions
- `Mohamed_Abdullahi_Osman_CV.pdf` — CV used by the Download CV button
- `assets/` — uploaded profile, suit and logo images

## Run
Open `index.html` in a browser.

## Contact form
The contact form uses FormSubmit and is configured for `mohamedgaayac@gmail.com`.
On first submission, FormSubmit may send a confirmation email. Replace the `_next` value in `index.html` with your real deployed website URL if you publish the site online.
